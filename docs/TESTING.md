## 外部浏览器图片验收

外部 Chrome 自动化分别验证 `127.0.0.1:4173` 同类服务地址和 `localhost`：首次加载、刷新、新会话、列表、沉浸预览、原尺寸、拼图及请求失败后重试。自动化使用隔离端口 4174；另在真实用户库的 4173 Chrome 新会话核验 15/15 个可见照片已解码，截图显示正常，不修改用户选片状态。

缺失缩略图/预览已增加原片重新生成；请求失败、原片不存在、解码失败提供状态和重试。**用户先前故障会话的根因尚未复现，不能将其标为已定位修复。** 若仍发生，需要故障页面的实际地址、失败图片请求状态和控制台错误；未关闭浏览器安全机制或开放任意跨域。Edge 尚未实际验收。

## 精筛交互修正（2026-10-11）

- 精筛改为平铺网格，可按元数据和 AI 标签领域筛选；空格、双击、按钮进入沉浸，空格或 Esc 返回，范围保持不变。
- 精筛沉浸只有保留／不要，Z 不决定；保存成功下一张、失败停留、撤销、已精筛回看和无标签选片均已覆盖。
- 移除人工打标界面及直接写入照片标签的接口，保留历史标签数据；候选标签库的编辑仅用于定义 AI 分类范围。
- AI 标签分领域 AND／OR 筛选使用模拟模型真实 HTTP 分析结果验证，不通过人工写标签构造浏览器验收数据。
- 分类运行时显示进度，完成后自动消失；暂停、处理中和失败状态仍提供继续／重试操作，已完成创作也不占用任务栏。新增任务可见性自动化，并用真实 HTTP 模拟分类阻塞／完成验证进度条的出现与消失。

## 看图搭配与快捷组合（2026-10-11）

- 候选检索验证：12 张上限、标签召回、主体／景别分配、相似组多样性、低排名锁定照片和当前画布照片保留。
- 多模态请求验证：真实 JPEG 与逐张 ID 配对，长边上限 1024，清除 EXIF，提示词要求观察色彩、构图、视线与人物朝向；浏览器模拟 HTTP 服务收到实际图片数据并返回合法推荐。
- 随机组合验证：指定类型三拼、自由三／四拼、重复换组、不同照片约束、锁定位置、必选照片、范围校验、素材不足与唯一组合提示。
- 浏览器实测六张已 AI 分类照片按“近景人像／远景风景／远景人像”顺序随机填入，重复点击换组，锁定首格后不替换，再切换四拼；整个随机过程调用模型次数为零。截图 `test-results/quick-pairing.png`。
- 多图等待与单张分类分别设置超时，看图搭配允许 180 秒；超时不自动再次发送图片。自动化覆盖超时不重试。
- 真实服务：`qwen3.8-flash` 接收 12 张合成参考图，看图搭配通过，60.548 秒返回三拼；理由包含色彩过渡、太阳位置衔接及人物朝向。结果保存于本机 `.local/qa/pairing-<时间戳>/result.json`。验证的是真实多图请求与结构化返回，不代表真实旅行样片上的审美准确率。
