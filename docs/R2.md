# R2 压缩展示图

R2 用来分发列表、手机远程初筛／精筛、沉浸浏览、作品集、分享页和创作的压缩展示图。图片文件直接从 R2 返回，不再经过家里的上传带宽。原片、AI 原始处理流程和下载内容保持不变，原片下载仍由本机服务器或已授权的电脑文件提供。

列表：WebP 长边 480 像素、质量 72；手机和平板沉浸：1080 像素、质量 80；桌面：1600 像素、质量 80。自动旋转、去除 EXIF、不放大小图。只有主动查看原尺寸、下载或输出高分辨率成品时使用原片。

电脑文件夹导入会同步一份去 EXIF 的 1600 像素展示图，**不上传本地原片**。已有本地照片请在原电脑点击“重新连接文件夹”补同步；手机不能凭空读取另一台电脑的文件夹。设置 → 图片存储可以查看同步数量、大小、失败数并重试。

## 开通与部署

先在 Cloudflare 控制台开通 R2。使用私有 Standard 桶；不要开启 r2.dev 或把桶绑定为公开图床。实际免费额度和超额价格以 [R2 价格页](https://developers.cloudflare.com/r2/pricing/) 为准，Worker 的请求费用单独计算。

准备一个 Cloudflare API Token，只授予所选账号的 Workers Scripts Write、Workers R2 Storage Write、Workers Custom Domains Write，以及所选域名的 DNS Read、Zone Read。不得提交 Token、付款信息或本地配置。

```sh
export CLOUDFLARE_ACCOUNT_ID='你的账号 ID'
export CLOUDFLARE_ZONE_ID='你的域名 Zone ID'
read -s CLOUDFLARE_API_TOKEN
export CLOUDFLARE_API_TOKEN
export PHOTO_SELECTOR_PUBLIC_URL='https://photos.example.com'
export PHOTO_SELECTOR_MEDIA_HOST='img.example.com'
# 如需要从其他已允许的地址使用 Canvas，填入完整 Origin，逗号分隔。
export PHOTO_SELECTOR_ALLOWED_ORIGINS='http://localhost:4173,http://127.0.0.1:4173'
node scripts/deploy-r2.mjs
unset CLOUDFLARE_API_TOKEN
./deploy.sh restart
```

脚本创建或复用专用桶、部署 `cloudflare/media-worker.mjs`，配置图片子域名，并生成权限为 0600 的 `<数据目录>/r2.json`。只将应用与 Worker 之间的专用密钥保存在此文件，不保存 Cloudflare API Token。`PHOTO_SELECTOR_DATA_DIR` 默认为 `.local`；桶名和 Worker 名可通过 `PHOTO_SELECTOR_R2_BUCKET`、`PHOTO_SELECTOR_MEDIA_WORKER` 改写。已有 DNS 或其他 Worker 占用的子域名不会被覆盖。

Mac 的 `./deploy.sh` 仍负责本机应用；修改 Worker 后需重新运行 R2 部署脚本。Docker 使用相同的数据目录配置：把生成的 `r2.json` 通过 `docker compose cp .local/r2.json web:/data/r2.json` 放到实际数据卷中，再 `docker compose restart`。复制后运行 `docker compose exec -u root web chown node:node /data/r2.json`，让文件归应用用户所有且保持 0600；不要把密钥烘焙进镜像。Mac 和 Docker 不自动共用照片库。

## 权限、失败与清理

- R2 桶保持私有。应用确认登录／分享密码后签发五分钟票据；Worker 每次取图都向应用核验会话、照片状态、分享范围与有效期，**先授权再读取边缘缓存**。撤销分享或退出登录后，旧票据也失效。已下载的文件不能追回。
- 管理端和分享端沿用权限范围；旧链接、篡改参数、其他照片 ID 都不能绕过校验。CORS 仅允许配置的应用地址及带有效票据的重定向请求。
- 本机必须在线以处理授权、AI 和原片下载。R2 减少图片传输带宽，不代替整个应用服务器。
- 后台最多两份展示图同时上传，上传后校验摘要和大小，进度写入 SQLite；每分钟补同步、重试及清理。失败时继续使用本机压缩图，浏览器图片加载失败也能回退。
- 初筛淘汰满三小时，仍按原有引用保护清理。R2 副本在下一次检查时删除，删除失败保留任务重试；照片已清理或分享已撤销后，即使删除尚未成功，也不能通过 Worker 读取。
- 分享快照有独立展示副本，撤销不会误删作品集中的原片。创作保留 PNG/JPEG 成品，R2 只分发压缩预览；高清下载保持原格式。
- 关闭 R2：先保留 `r2.json` 备份，将该文件移出数据目录后重启；应用回到本机压缩图。此操作不删除云端数据，彻底停用时另行清理专用桶及 Worker。

## 验证

```sh
node --test test/display.test.mjs test/r2.test.mjs
npm run check
npm run test:browser
```

测试涵盖旋转与 EXIF、尺寸和原片不变、本地目录仅同步预览、请求去重、失败回退、重启复用、跨照片隔离、分享密码／过期／撤销、缓存命中仍鉴权、受控 CORS、删除重试。真实手机体验和实际网络速度需要实机复测，浏览器模拟不代表实机通过。
