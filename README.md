# 选片助手

中文、暗色的本地网页选片工作台。照片导入后在本机处理，相似度使用 Apple Vision；多模态模型由你自行配置。

## 启动网页版

需要 Node.js 24 或更新版本。Mac 的本地 Vision 与钥匙串功能需要 Apple Command Line Tools（可通过 `xcode-select --install` 安装）。

```sh
npm ci
npm run build:vision
npm run dev
```

浏览器打开 **http://127.0.0.1:4173**。默认仅监听本机，不需要登录。服务运行期间可保持浏览器打开。

不构建 Vision 时也可以启动网页：相似度降级为传统感知哈希，API 密钥仅保存在本次服务进程内。界面会显示实际分析引擎及密钥保存方式。

生产构建的本机运行方式：

```sh
npm run build
NODE_ENV=production npm start
```

## 使用流程

1. **导入**：新建旅行，选择 JPEG 照片或整个文件夹，也可拖入文件。服务分批保存副本和预览，原文件不会改动。
2. **沉浸选片**：点击“沉浸选片”或双击照片。相似组直接铺开，悬停放大；独立照片居中，两侧前后照片虚化。支持滚轮缩放、双击放大、拖动、原尺寸查看和全屏。
3. **三种决定**：保留、待定、不要，分别对应 `1 / 2 / 3`；`P / U / X` 也可以。左右键切组，`⌘Z` 撤销，`Esc` 返回。默认不自动跳过，单张可开启“选择后自动下一张”。
4. **分类和精筛**：按标签、场景、焦段、横竖方向、日期或状态筛选。人工标签不被 AI 覆盖；“喜欢”独立于三种决定。作品集可排序、移除、锁定，并复用同一照片。
5. **AI 标签**：在“模型与服务设置”填写 Base URL、模型名和 API Key；测试图片理解、保存后选择照片开始分析。可使用兼容 Chat Completions 的云端或本地服务。默认不会自动上传。
6. **拼图**：在工作室选择三拼、四拼或单张，点击位置再替换照片。拖动调整构图，滑块缩放，也可交换顺序、锁定和撤销。聊天推荐先形成候选，点击“应用到画布”才采用。
7. **导出**：添加文字或 PNG 水印、相框并保存预设；导出 JPEG 拼图、批量单张成品或入选原片 ZIP。批量单张保留原照片比例，原片 ZIP 保持文件内容。默认优先导出照片库当前所选，其次当前作品集，最后为初筛保留照片。

## 模型设置

- Base URL 示例：`https://你的服务地址/v1`，本地服务示例：`http://localhost:1234/v1`。
- 模型必须支持图片输入；点击“测试图片理解”会发送一张很小的红色测试图并核验返回结果。
- 不兼容 `response_format` 的服务可关闭“JSON 模式”；返回数据仍接受本地校验。
- Mac 已构建原生助手时，密钥存入钥匙串，按服务地址隔离，不写入 SQLite、浏览器缓存或 Git。
- 手动启动分析时，只发送去除 EXIF、长边不超过 1536 像素的预览图。请求包含照片内容，服务商仍会按其政策处理数据。
- 失败会显示原因。认证失败暂停队列；限流和临时错误有限重试；可以暂停、取消、继续或重试失败照片。
- 会显示服务返回的 token 用量，不假设第三方定价。

## 数据与限制

- 默认数据目录：项目下 `.local/`；用 `PHOTO_SELECTOR_DATA_DIR` 可改到其他位置。端口可用 `PORT` 设置。
- 网页导入会在本机保存一份原片副本；因此需要额外磁盘空间。浏览器目录选择不会赋予服务原文件路径访问权。
- 项目、人工选择、分组、草稿和进度存入 SQLite；重启后恢复。本地暂停状态会保留，未完成 AI 队列重启后暂停，等待用户继续。
- 相似度提供三个档位，可手动拆组、合组、改场景名和代表图。清晰度、曝光和模型意见只是提示，不自动删图。
- 等效焦距优先取 EXIF，缺失时可以手动设置画幅系数，否则显示未知。
- 首版只支持 JPEG；不包含 RAW 显影、云同步、专业修图软件评级同步或发布朋友圈。
- 当前交付是**网页版验证服务**。最初的 SwiftUI 启动骨架保留用于后续桌面版本，不代表完整原生应用。
- 目前的自动测试使用合成照片和模拟模型响应。真实旅行照片的分组准确率、第三方模型效果需要配置服务并使用实际照片复核。

## 开发和验证

```sh
npm run check          # 自动化测试 + 网页生产构建
npm run test:browser   # 本机 Chrome 的完整交互流程
npm run test:all       # 上述所有检查
npm run benchmark     # 3000 张合成 JPEG 的导入、Vision 和恢复检查
bash scripts/test.sh  # Swift 基础测试（不要求 XCTest / 完整 Xcode）
```

浏览器测试在独立的 `.local/e2e` 工作目录和 4174 端口运行，不修改日常照片库。没有 Chrome 时可安装 Playwright Chromium，然后用 `CI=1 npm run test:browser`。失败截图和现场信息保存在 `test-results/`，不提交到仓库。

- `server/`：本机 HTTP 服务、持久化、分析队列、多模态适配及导出。
- `shared/`：浏览器与服务共用的分组展示、检索及版式计算。
- `web/`：照片库、沉浸选片、模型设置、拼图工作室。
- `Sources/VisionWorker/`：原生 Vision 特征提取、人脸位置和钥匙串桥接。
- `test/`：单元、服务集成和实际浏览器测试。

每个功能测试通过后独立提交并推送；GitHub Actions 在 macOS 上运行构建、原生测试和浏览器验证。完整记录见 [测试与验收](docs/TESTING.md)。
