# 选片助手

中文暗色的本机网页选片工具。照片与本地分析留在本机；AI 服务地址、模型和密钥由用户配置。

## 启动

需要 Node.js 24+。Mac 的 Apple Vision 和钥匙串需要 Apple Command Line Tools。

```sh
npm ci
npm run build:vision
npm run dev
```

打开 **http://127.0.0.1:4173/** 或 **http://localhost:4173/**。支持外部 Chrome；默认仅监听本机。不构建原生助手时使用传统感知哈希，密钥只保存在服务进程内存。

生产模式：

```sh
npm run build
NODE_ENV=production npm start
```

## 两轮选片

1. **创建项目、导入 JPEG**：照片或文件夹均可导入，自动提取元数据和分析相似度。原文件不改动，本机保存一份原片副本。
2. **初筛**：未处理照片集中在初筛工作区。Z 待定、X 保留、C 不要；保存成功后自动下一张。“已筛选”可回看和改选。
3. **作品集 → 初筛**：收纳第一轮保留和待定照片。点选人工标签，或启动 AI 分类；可以多标签筛选。
4. **沉浸式精筛**：第二轮独立决定，保留和待定进入最终作品。第二轮不要仍保留在初筛区，第一轮结果不被覆盖。
5. **作品集 → 最终作品**：作品集默认页。排序、锁定、跨作品集复用、拼图和导出都从这里进行。

| 操作 | 快捷键 |
|---|---|
| 待定／保留／不要 | Z／X／C |
| 进入或退出沉浸 | 空格 |
| 退出沉浸（包括全屏） | Esc |
| 前后照片 | 左右方向键 |
| 撤销 | Command-Z／Ctrl-Z |

列表中的 Z/X/C 修改第一轮；第二轮决定在沉浸式精筛内完成。输入框不触发这些快捷键，保存失败不跳图。

相似组默认叠放，可展开并收起。沉浸最多显示同组前后及当前三张，当前图居中；点击或横向滑动切换，悬停仅放大显示，不改变决定对象。普通照片前后虚化。滚轮缩放、放大后拖动平移、原尺寸和人脸定位保留。

## 分类

- 标签按主体、景别、环境、风格组织；支持自定义、改名、合并、保存个人常用项和批量点选。
- 同一项目共享标签，标签自动形成小分组。多个标签可选择“同时满足”或“满足任一”。
- 人工添加和移除优先于 AI，重新分析不会恢复被人工排除的标签。
- **AI 流程**：补充常用标签 → 按时间和数量比例抽样 → 编辑并确认候选标签库 → 批量标注。确认前不会进行全量分类。
- 抽样去除精确重复，取唯一照片的 10%，至少 12、最多 60 张；不足 12 张全部抽取。时间分层覆盖缺失日期，进度与抽样名单可恢复。
- 每张分析请求注入确认后的标签与定义，拒绝库外标签；运行中的任务固定使用当次标签库和服务配置。初筛未处理或不要的照片不能送去分析。

## 服务设置和隐私

填写 API Base URL、模型名称、API Key。使用支持图片输入的 Chat Completions 兼容接口，支持 HTTPS 云服务及 localhost HTTP 本地服务。连接测试发送红色测试图并验证识别；不兼容 JSON 模式的服务可以关闭该选项。

Mac 构建原生助手后，密钥按服务地址隔离存入钥匙串，不写进 SQLite、浏览器缓存或 Git。图片分析由用户手动启动，发送的是去除 EXIF、长边不超过 1536 像素的预览。身份验证失败暂停，限流与临时故障有限重试，支持取消和重试失败照片。

## 拼图、导出与兼容

三拼、四拼、单图；比例、裁剪、缩放、位置、交换、锁定、间距、背景色；文字或透明 PNG 水印、相框和预设。聊天先生成候选方案，应用后才改变画布。默认从最终作品取图，包括第二轮待定；可明确选图或按状态筛选。

默认输出 sRGB JPEG、长边 3000 像素、质量 90%，去除 EXIF/GPS；单图不放大低分辨率原图。原片 ZIP 保持字节内容，同名自动编号。

数据库默认在 `.local/`，可用 `PHOTO_SELECTOR_DATA_DIR` 修改；端口由 `PORT` 设置。升级两轮状态前自动备份到数据目录 `backups/`：旧 keep/reject 保留为第一轮，旧 unseen 视为未筛选，不推断第二轮结果。已有自建作品集和标签保留；旧草稿包含非最终照片时提示重建，原草稿归档到本地数据库，重建可撤销。

图片使用同源 HTTP 地址。缺失缩略图和预览会从原片恢复；原片缺失、请求或解码失败会显示重试入口。外部 Chrome 已实测，但用户先前报告的旧会话问题尚未复现其根因。

## 验证

```sh
npm run check
npm run test:browser
bash scripts/test.sh
npm run benchmark
```

浏览器测试使用每次独立的 `.local/e2e/<随机ID>` 测试库与 4174 端口，不修改个人照片库。没有 Chrome 时，先运行 `npx playwright install chromium`，再用 `CI=1 npm run test:browser`。

真实照片、数据库、缓存、导出文件、密钥和构建产物不提交。功能分别测试、提交、推送 GitHub 私有仓库，macOS CI 验证构建与浏览器流程。详情见 [测试记录](docs/TESTING.md)。

当前交付为网页版；保留的 SwiftUI 骨架不代表已完成原生桌面版。首版不含 RAW 显影、云同步、专业软件评级同步或自动发布。真实第三方 AI 服务尚未联调，自动化使用模拟响应；分组阈值仍需真实旅行样本校准。
