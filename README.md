# 选片助手

中文暗色的本机网页选片工具。照片与本地分析留在本机；AI 服务地址、模型和密钥由用户配置。

## 启动

需要 Node.js 24+。Mac 的 Apple Vision 和钥匙串需要 Apple Command Line Tools。

```sh
npm ci
npm run build:vision
npm run dev
```

打开 **http://127.0.0.1:4173/** 或 **http://localhost:4173/**。支持外部 Chrome，默认仅监听本机。不构建原生助手时使用传统感知哈希，密钥只保存在服务进程内存。

生产模式：

```sh
npm run build
NODE_ENV=production npm start
```

## 三阶段选片

1. **创建项目、导入 JPEG**：照片或文件夹均可导入，自动读取元数据、分析相似度。原文件不改动，本机保存一份原片副本。
2. **粗筛**：默认只看未处理照片；Z 待定、X 保留、C 不要，保存成功自动下一张。“已粗筛”回看决定。待定和保留进入精筛。
3. **精筛**：照片平铺，可按元数据及 AI 标签筛选。空格、双击或“开始精筛”进入沉浸式，空格／Esc 返回网格；只有 X 保留、C 不要，Z 不作决定；“已精筛”回看、改选。不要不抹掉粗筛历史。
4. **作品集**：精筛保留进入候选池，默认显示未归入作品集的照片，可切换全部。创建多个作品集，批量加入、排序、锁定；同一照片可在多个作品集中复用。

没有标签、没有配置 AI，也可以完成精筛、作品集分类和手动拼图。保存失败不跳图；Command-Z／Ctrl-Z 撤销决定并恢复当前照片。输入框不触发选片快捷键。

粗筛列表和沉浸共用 Z/X/C。空格进入或退出沉浸，Esc 退出（包括浏览器全屏），左右方向键切图。相似组默认叠放，可展开和收起；沉浸最多显示当前及前后共三张，同组保持清晰，普通照片前后虚化。点击或横向滑动切换，悬停仅放大显示，不改变决定对象。支持缩放、拖动平移、原尺寸和人脸定位。

## 分类与任务

- **AI 分类**：直接使用现有项目标签库；无项目库时使用内置分类，无需抽样。默认跳过已完成当前版本的照片；未选中照片时处理当前筛选范围，显式选中时只处理选中范围，“重新分析”可强制更新。
- **细化分类**：可选。补充常用标签 → 时间分层抽样 → 编辑确认候选标签库 → 分类。抽样去除精确重复，取 10%，至少 12、最多 60 张；不足 12 张全部取。
- AI 成功结果为一个主体、一个景别、最多五个附加标签。主体含人像、多人合照、风景、宠物、建筑、美食、其他；景别含特写、近景、中景、远景、全景、不确定。
- 筛选按主体／景别／环境／风格／其他折叠分区，可选同时满足或满足任一。照片卡片展示全部有效标签。
- 照片标签仅由 AI 分类生成，不设人工打标步骤。细化分类仍可编辑候选标签库；已有历史标签及修改记录保留。
- 默认抽样并发 4、分类并发 8，同一图片理解服务总并发 8，设置中分别可调 1–16。429 遵循等待时间并降低实际并发，临时故障有限重试，认证失败暂停。
- 三个页面共享任务进度。暂停停止派发，已发请求完成后保存；取消阻止迟到结果写入。重启后未完成任务暂停待继续，已完成结果不重复请求。
- 每次任务固定模型、配置和标签库版本，服务端拒绝分析粗筛未处理／不要的照片；结构与库外标签均校验。

## 作品集与创作

作品集可编辑描述，分为“照片”和“创作”。拼图、AI 封面、文案单独保存，不混入原片或选片队列；再次生成保留旧版本。

- **拼图**：默认从全部精筛保留取图，也可指定作品集或选中照片。AI 推荐和手工替换遵守同一范围，草稿按作品集或独立选择保存。三拼、四拼、单图，支持裁剪、缩放、交换、锁定、间距、背景、水印、相框。可保存到作品集或导出。
- **生成文案**：用户点击后遍历作品集全部有效原片，复用已有描述，缺失时补充图片理解；分批汇总后结合描述生成标题和正文。文案可编辑。
- **生成封面**：从全部内容总结中选最多四张参考照片，生成一张图片；默认 3:4、1536×2048，可改比例。作品记录来源、参考照片、提示词、模型和时间，图片下载到本地保存。
- 部分失败保留已有描述和总结。生图超时且结果未知不自动重复提交；若已有输出地址但下载失败，重试继续下载。

## 服务设置和隐私

“图片理解”填写 API Base URL、模型、API Key，采用支持图片输入的 Chat Completions 兼容接口。支持 HTTPS 云端及 localhost HTTP 本地服务。连接测试发送合成测试图；不兼容 JSON 模式时可以关闭。

“图片生成”独立配置，默认 `wan2.7-image`，接口：

```text
https://token-plan.maas.qianwenaiapi.com/api/v1/services/aigc/multimodal-generation/generation
```

默认引用图片理解服务的钥匙串密钥，也可单独填写地址和密钥。使用原生图片生成协议，并发 1，每次明确生成一张，不经过 Chat Completions。

Mac 构建原生助手后，密钥按服务地址隔离存入钥匙串，不写进 SQLite、浏览器缓存或 Git。图片理解与生成仅在用户启动时调用，参考图／分析图去除 EXIF，长边不超过 1536 像素。运行中任务保留配置快照，不保存密钥副本。

## 导出、数据与兼容

默认输出 sRGB JPEG、长边 3000 像素、质量 90%，去除 EXIF/GPS；单图不放大低分辨率原图。原片 ZIP 保持字节内容，同名自动编号。

数据库默认在 `.local/`，可用 `PHOTO_SELECTOR_DATA_DIR` 修改，端口由 `PORT` 设置。状态迁移前备份到数据目录 `backups/`。旧精筛待定迁为保留并记录原值；粗筛、人工标签、已有作品集成员和分析成果保留。旧未完成分类任务暂停待继续。含非最终照片的旧拼图草稿需明确重建，原草稿归档且可撤销。

图片使用同源 HTTP 地址；缺失缩略图／预览从本地原片恢复。缺失、请求或解码失败显示重试入口。外部 Chrome 回归已通过，先前用户旧会话故障根因尚未复现。

## 验证

```sh
npm run test:all
bash scripts/test.sh
npm run benchmark
# 可选：使用本机已配置服务，发送三张合成照片，产生真实调用费用
LIVE_AI_TEST=1 node scripts/live-smoke.mjs
```

浏览器测试在独立 `.local/e2e/<随机ID>` 测试库与 4174 端口运行，不修改个人照片库。没有 Chrome 时，先运行 `npx playwright install chromium`，再用 `CI=1 npm run test:browser`。

`qwen3.8-flash` 图片理解和 `wan2.7-image` 参考图生成已用合成素材完成真实联调；模拟与真实验证分别记录在 [测试记录](docs/TESTING.md)。真实照片、数据库、缓存、输出、密钥和构建产物不提交。各功能分别测试、提交、推送私有仓库，macOS CI 验证。

当前交付为网页版。SwiftUI 骨架不代表已完成原生桌面版；不含 RAW 显影、云同步、专业软件评级同步或自动发布。相似分组阈值仍需真实旅行样本校准。
