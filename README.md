# 选片助手 · 照片墙

个人照片墙与作品集管理工具。首页展示已归入作品集的照片，导入和两轮筛选用于入库；作品集默认私有，可单独分享和下载。

## 一键部署

安装并启动 Docker 后：

```sh
git clone git@github.com:WuJean/photo-selector.git
cd photo-selector
./deploy.sh
```

打开 [localhost:4173](http://localhost:4173)。首次部署生成管理员密码，读取后在网页「设置」修改：

```sh
docker compose exec -T web cat /data/admin-initial-password
```

仓库为私有，需要拥有访问权限。更改端口、HTTPS 域名、备份及重置见 [Docker 部署说明](docs/DEPLOYMENT.md)。更新重新运行 `./deploy.sh`，不会自动清库。

## 使用流程

1. **导入与筛选**：连接电脑文件夹、普通上传，或粘贴公开 JPEG 图片直链（支持多行）。已经选好的照片勾选「直接加入作品集」，导入后进入待归集列表。
2. **初筛**：Z 待定、X 保留、C 不要，成功保存后自动下一张。空格进入／退出沉浸，Esc 退出，左右切换，Command-Z／Ctrl-Z 撤销。相似组可展开和重新叠放，沉浸最多显示三张。
3. **完成初筛**：必须处理整个批次；点击带有淘汰数量的完成按钮后清理服务器淘汰副本。此前可撤销，清理后服务器副本不可恢复。电脑源文件不删除。
4. **精筛**：平铺网格、元数据和 AI 标签筛选；空格沉浸，X 保留／C 不要。标签不是选片门槛。网络入选照片先保存到电脑文件夹，大小、摘要核对成功后清理服务器中转。
5. **作品集**：从待归集批量加入作品集，同一照片可跨作品集复用。支持封面、描述、拖动排序、批量置顶、移除和下载。完成批次收进历史。
6. **照片墙**：聚合所有作品集照片，同一资产只展示一次；按作品集或标签筛选，全屏缩放、拖动、下载。每次增加 100 张，逐步加载。

## 电脑文件夹与存储

- 文件夹模式首版面向桌面 Chrome／Edge，要求 HTTPS 或 localhost／127.0.0.1 安全上下文。**默认只上传元数据，不上传本地原片**。
- 浏览器 Worker 提取 EXIF、SHA-256、感知哈希及缩略图。服务端存资产、批次决定、标签和作品集关系；目录凭据只在当前浏览器 IndexedDB。
- 刷新或重开页面恢复关联；授权失效、换浏览器、换访问地址或移动文件后，点「重新连接文件夹」，按摘要匹配。浏览器之间不共享目录授权。
- 不支持目录访问时可普通上传，原片保存在服务器。上传模式与电脑文件夹模式是不同存储方式。
- 网络导入只接受公开 HTTP(S) 图片直链，不解析网盘／相册网页。校验 DNS 和每次重定向，阻止内网请求；并发 3，单图上限 100 MB、解码上限 1.2 亿像素。
- 保存网络原片时才申请目录写权限；重名自动追加序号，写失败或校验失败保留服务器文件。筛选永远不会删除电脑源文件。
- 清理任务持久化并自动重试，保护作品集、分享、其他批次及运行任务引用；释放量按实际删除的字节统计。
- 不包含图床接入或微信数据迁移。本轮没有修改微信小程序和云端数据。

## 私有分享与下载

作品集点击「分享」生成随机链接，可设置有效期、访问密码、下载关闭／展示版／原片。浏览器将必要副本准备完毕并校验后才发布；仅展示时上传去 EXIF 的展示副本，开放原片下载才另外上传原片。发布后管理者电脑离线不影响访问。

分享是发布时的快照；后来修改作品集不会悄悄改变已有链接，需要重新分享。撤销立即阻止新请求并清理在线副本，到期自动失效。访客无法访问未分享照片或管理 API。关闭下载会移除下载入口并拒绝下载接口，但浏览器能看到的展示图片无法禁止截图或另存。

本地批量下载逐张打包，Chrome／Edge 可直接写 ZIP 文件，避免同时载入全部原片；不支持文件写入时使用有 128 MB 上限的内存后备。分享 ZIP 在服务器流式打包。

## AI 分类与创作

设置填写图片理解 **API Base URL、模型名称、API Key**，兼容图片输入的 Chat Completions。默认直接按现有库分类，可选「细化分类」抽样、确认新标签后再全量分类。主体／景别各一个、附加标签最多五个，领域分区筛选、全部显示。默认抽样并发 4、分类并发 8，共享上限 8，可调 1–16。未完成任务显示进度，完成后隐藏，支持暂停、取消、重试和重启继续。

AI 只按需接收去除 EXIF、最长边 1536 像素的预览；本地文件夹离线时任务等待重连。使用过的预览在没有任务引用后回收，未使用的准备文件一小时回收。真实服务配置与凭据不会进入 Git。

作品集提供：

- **拼图**：三拼、四拼、单图，裁剪、缩放、交换、锁定、间距、背景、文字／PNG 水印、相框；浏览器读取本地原片并合成，无需上传原片。默认 sRGB JPEG，长边 3000、质量 90，单图不放大低分辨率原图。
- **AI 搭配**：先用标签缩小候选，再给多模态模型逐张看图，比较色彩、构图、视线方向，形成可编辑方案。来源可限定作品集或选中照片。
- **随机模板**：内置人像近景／风景远景／人像远景，逐格主体与景别可自定义保存；随机组合无需模型，缺项明确提示。
- **文案／封面**：遍历整个作品集，缺少描述的照片补充理解，分批总结，结合作品集描述生成。封面模型独立配置，默认 `wan2.7-image`，并发 1。已知生成结果仅重试下载，超时结果未知时不自动再次生图。
- **创作区域**：拼图、AI 图片、文案与原片分开，记录来源和参数，再生成保留旧版本。保存拼图会上传合成成品，电脑原片仍留在电脑。

## 本地开发

Node.js 24+：

```sh
npm ci
npm run dev
```

默认 [127.0.0.1:4173](http://127.0.0.1:4173)，数据目录 `.local/`，初始密码 `passwd`，首次登录必须修改。可用 `PHOTO_SELECTOR_DATA_DIR`、`PORT` 调整。Mac 可选 `npm run build:vision` 启用服务器上传照片的 Apple Vision 分析；浏览器文件夹使用浏览器 CV，不依赖 Swift。Docker 使用 Linux CV。

```sh
npm run check          # 自动化测试与生产构建
npm run test:browser   # 新照片墙浏览器回归
npm run test:docker    # 容器重建、恢复、登录、图片和模拟 AI
node scripts/benchmark-wall.mjs  # 3000 张浏览器文件夹性能验收
```

验证范围和限制见 [测试记录](docs/TESTING.md)。`test/browser/` 是旧三阶段界面的历史测试，新入口使用 `test/wall-browser/`。

## 代码结构

- `web/src/WallApp.jsx`：照片墙、作品集和批次筛选。
- `web/src/local-media.js`、`photo-worker.js`、`render-local.js`：本地句柄、后台解码、浏览器拼图。
- `server/library.mjs`、`database.mjs`：资产／批次／作品集，SQLite 持久化。
- `server/auth.mjs`、`shares.mjs`：管理员会话、私有分享。
- `server/network-import.mjs`、`cleanup.mjs`、`media.mjs`：受限下载、清理、AI 预览。
- `server/ai.mjs`、`vocabulary.mjs`、`scheduler.mjs`、`creations.mjs`：AI 任务与创作。
- `shared/`：筛选、标签和统一排版规则。
- `server/reset-library.mjs`：显式业务重置，保留设置、凭据和管理员。

数据卷、照片、密钥、导出、构建结果和本地配置均不提交。单管理员、单应用实例；不包含多用户隔离、RAW 显影、云同步或自动发布朋友圈。

首次默认密码为 `passwd`；登录后必须先设置至少 12 位的新密码。已修改的密码不会因重启或升级而重置。
